# Partner Contract Exceptions

This document is part of the fictional Northstar Systems knowledge base. Values in it are controlled evaluation facts, not general business guidance. Apply only the rules whose stated scope matches the case; do not substitute customary practice for a missing Northstar rule.

## Scope

This policy covers partner exceptions, strategic partners, approval overrides. A rule is applicable only when the case facts satisfy its stated condition. Identifiers, queue names, codes, thresholds, and durations are literal Northstar values. Similar-looking values in neighboring documents are distractors unless a rule or cross-reference makes them relevant.

## Rules

1. Contracts tagged PINE-6 use a single concession ceiling of 24.3 percent under Team SABLE with code BIRCH-72.
2. PINE-6 is authoritative over the ordinary partner approval bands but does not override regional data-handling restrictions.
3. For partner-sold contracts, verified duplicate-billing refunds route here rather than through refund exception D-8.
4. A PINE-6 duplicate-billing refund up to EUR 9,260 may be approved by Team SABLE using code BIRCH-72; larger amounts return to the applicable regional or standard refund policy.
5. APAC billing overrides can still alter the payment instrument for a PINE-6 refund after approval authority has been determined.

## Exceptions

- PINE-6 replaces ordinary partner concession bands.
- Partner-sold duplicate billing is excluded from D-8 and uses the partner exception route.

## Precedence

- PINE-6 controls partner approval authority, while regional policy can still control payment instrument or data handling.
